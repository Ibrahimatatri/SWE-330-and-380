# Data

**Issue:** #7. This folder holds the instructions for obtaining the GitSkills release, the generated validation sheets, and (locally only) intermediate pipeline files. The release itself is not committed: it is 44 GB, and anyone can download it from Zenodo.

## Get the release

```bash
curl -C - -o agent_skills_release.db 'https://zenodo.org/records/21875637/files/agent_skills_release.db?download=1'
md5 agent_skills_release.db   # Linux: md5sum
```

- Expected size: 44,388,249,600 bytes. Expected MD5: `b058631fb1926efac6e82a4706646742`.
- `-C -` resumes an interrupted download; run the same command again from the same folder.
- Keep the file anywhere (for example `data/raw/`, which git ignores) and pass its path to the pipeline: `make pipeline DB=/path/to/agent_skills_release.db`, or set `SKILLGUARD_DB`.
- The pipeline opens the file read-only (`mode=ro&immutable=1`), so it never modifies it.

Version, license (CC-BY-4.0), tables, and verified counts are in [`DATA_DICTIONARY.md`](../DATA_DICTIONARY.md).

## Layout

| Path | Committed? | Contents |
|---|---|---|
| `data/raw/` | No (git-ignored) | The release file, if you keep it here |
| `data/interim/` | No (git-ignored) | Index, sample, findings, outcomes; regenerated by `make pipeline` |
| `data/annotations/` | Yes | Validation sheets: hashes, GitHub links, and labels only, no Skill text |

## Ethics

- Results are reported in aggregate; we do not name or accuse authors. Evidence snippets are short, and secrets are masked.
- The release is CC-BY-4.0: cite it when reporting results. We do not redistribute Skill text.
- Skill text is handled only as data; the pipeline never runs commands or scripts or fetches URLs found in it.
